# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub instead:
[Report a vulnerability](https://github.com/gyorgybalazsi/surrealdb-explorer/security/advisories/new)
(the repository's **Security** tab → **Report a vulnerability**).

Include what you found, how to reproduce it, and the affected version or commit.
I'll acknowledge the report as soon as I can and keep you posted on the fix.

## Supported versions

Only the latest commit on `main` receives security fixes.
